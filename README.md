# Entre Cordas

Página estática sobre boxe criada para o trabalho de Desenvolvimento Web I.

É um guia visual e informativo: apresenta a origem da modalidade, seus quatro fundamentos básicos e como funciona uma luta.

## Tecnologias

- HTML5 para estruturar o conteúdo;
- CSS3 para cores, tipografia, layout responsivo e efeitos de interação.

O projeto não utiliza JavaScript, frameworks ou temas prontos.

## Arquivos

- `index.html`: conteúdo e estrutura da página;
- `style.css`: apresentação visual da página;
- `RELATORIO.md`: registro de aprendizagem e publicação.

## Personalização antes de publicar

No arquivo `index.html`, troque `SEU NOME AQUI` e `seuemail@exemplo.com` pelos seus dados. Você também pode adaptar os textos dos cartões para seus interesses.
