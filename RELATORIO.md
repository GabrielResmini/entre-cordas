## 1. Objetivo e tema escolhido

O objetivo deste trabalho foi publicar uma página web estática usando GitHub Pages. Escolhi o tema **“Entre Cordas”**, uma página sobre boxe, seus fundamentos e os valores de disciplina, técnica e respeito. O tema foi criado especificamente para esta atividade e não reutiliza o projeto da disciplina de Projeto Integrador.

## 2. Ferramentas utilizadas

- **Visual Studio Code:** utilizado para escrever e editar os arquivos do site.
- **HTML5:** usado para estruturar o conteúdo, como cabeçalho, navegação, seções e rodapé.
- **CSS3:** usado para definir cores, espaçamentos, layout em grade, tipografia e adaptação para telas menores.
- **Git:** usado para registrar o histórico do projeto por meio de commits.
- **GitHub:** usado para armazenar o repositório público.
- **GitHub Pages:** usado para publicar os arquivos estáticos na internet.

## 3. Passo a passo realizado

1. Criei uma pasta nova para o trabalho e abri essa pasta no editor de código.
2. Criei o arquivo `index.html` e organizei o conteúdo com elementos semânticos: `header`, `nav`, `main`, `section`, `article` e `footer`.
3. Criei o arquivo `style.css` e conectei a folha de estilos ao HTML pela tag `link`.
4. Testei o site localmente no navegador e corrigi detalhes de texto, espaçamento e visualização em tela menor.
5. Iniciei o controle de versão com `git init`, adicionei os arquivos com `git add .` e criei commits com mensagens claras.
6. Criei um repositório público no GitHub chamado `[NOME-DO-REPOSITORIO]`.
7. Conectei o repositório local ao remoto e enviei os commits com `git push`.
8. Nas configurações do repositório, acessei **Settings > Pages** e selecionei a publicação a partir da branch principal e da pasta raiz (`/(root)`).
9. Esperei a publicação e testei o endereço em uma aba anônima.

## 4. Conceitos aprendidos

Aprendi que o **Git** é uma ferramenta que registra mudanças no código em versões chamadas commits. O **GitHub** hospeda esse repositório on-line, facilitando o compartilhamento e a consulta ao histórico.

Também aprendi que o **GitHub Pages** transforma os arquivos estáticos de um repositório em um site público. Como o projeto possui um arquivo `index.html` na raiz, ele funciona como página inicial quando é publicado.

No HTML, reforcei o uso de elementos semânticos, que tornam a estrutura mais clara. No CSS, pratiquei variáveis de cor, Flexbox, Grid e media queries para deixar a página responsiva, sem usar JavaScript ou frameworks.
